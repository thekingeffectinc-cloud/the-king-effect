# The King Effect

Official storefront for **The King Effect** clothing brand — Home, Shop, About, Contact, and a bag/checkout flow.

Live site: https://thekingeffectinc-cloud.github.io/the-king-effect/

This repository holds the static storefront published with GitHub Pages. Secure Stripe checkout requires the brand's hosted checkout server (Node); on this static preview the bag works and checkout shows a notice until the server is live.
